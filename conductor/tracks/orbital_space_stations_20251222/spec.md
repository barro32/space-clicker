# Track Spec: Implement Orbital Space Stations

## Goal
Introduce the "Orbit" layer of progression by allowing players to build and manage Orbital Space Stations. This serves as a bridge between the initial planetary buildup and reaching the moons.

## Requirements

- **Explosions:** 
  - Rockets have a small chance to explode per launch.
  - Chain reactions (where one explosion triggers others) are disabled.
  - Explosion probability is kept low (e.g., 5%) for better gameplay flow.
- **Space Stations:** A new collection in the `GameState`.
  - Each station has a `level` and a `type` (e.g., Research, Logistics).
- **New Resource:** `Cargo`.
  - Generated by successful rocket launches (e.g., 0.1 per launch).
  - Used to build Space Stations.
- **Rocket Launches:**
  - Rockets no longer cost fuel to build.
  - Each launch attempt in `tick` costs 1 fuel.
  - Successful launches generate Cargo, Money, and Science.
- **New Actions:**
  - `buildSpaceStation()`: Build a new station in orbit.
  - `upgradeSpaceStation(id)`: Increase the level of a station.
- **Costs:**
  - Space Stations cost Cargo and Science.
  - Initial cost: 500 Cargo and 500 Science.
- **Benefits:**
  - Research Stations: Increase Science generation per tick.
  - Logistics Stations: Reduce the fuel cost of surface rockets or increase profit per rocket.

### 2. User Interface (UI)
- **View Switcher:** A way for players to switch between "Surface" and "Orbit" views.
- **Orbit View Component:**
  - A visual representation of the planet with orbiting stations.
  - Management panel for stations (build, upgrade, toggle types).
- **Navigation:** Clear indicators of where the player is and easy access to both views.

### 3. Integration
- Stations should integrate with the existing `tick` loop.
- UI should be consistent with the "Scientific and Industrial" tone.

### 4. Contracts System
- **Companies:** 10 persistent industrial entities (e.g., Titan Mining, Nova Research).
  - Each has a level and experience points.
  - Leveling up improves reward multipliers and contract size.
- **Contracts:**
  - **Types:** Delivery (Cargo), Research (Science), or Mixed.
  - **Conditions:** 
    - `Time Limit`: Contract fails if not completed within X seconds.
    - `Fragility`: Contract fails if more than Y rockets explode while active.
  - **Rewards:** Significant Money/Science boosts and Company XP.
- **UI:** A "Contracts" dashboard to view available offers and active mission status.

## Acceptance Criteria
- [ ] Player can switch between Surface, Orbit, and Contracts views.
- [ ] Player can build a Space Station in Orbit view if they have enough resources.
- [ ] Contracts are generated based on company levels.
- [ ] Active contracts track failures (explosions) and time correctly.
- [ ] Completing contracts grants rewards and levels up companies.
