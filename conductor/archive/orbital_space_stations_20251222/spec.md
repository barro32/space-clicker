# Track Spec: Implement Orbital Space Stations

**Status: COMPLETED (December 2025)**

## Goal
Introduce the "Orbit" layer of progression by allowing players to build and manage Orbital Space Stations. This serves as a bridge between the initial planetary buildup and reaching the moons.

## Requirements

### 1. Core Mechanics
- [x] **Explosions:** 
  - Rockets have a small chance to explode per launch (50% base, reduced by research).
  - Chain reactions disabled.
  - Explosions can be cleared for +1 science.
- [x] **Space Stations:** A new collection in the `GameState`.
  - Each station has a `level` and a `type` (Research or Logistics).
- [x] **New Resource:** `Cargo`.
  - Generated by successful rocket launches (0.1 per launch base).
  - Used to build Space Stations.
- [x] **Rocket Launches:**
  - Each launch attempt in `tick` costs fuel.
  - Successful launches generate Cargo, Money, and Science.
- [x] **New Actions:**
  - `buildSpaceStation()`: Build a new station in orbit.
- [x] **Costs:**
  - Space Stations cost 500 Cargo and 500 Science.
- [x] **Benefits:**
  - Research Stations: +10 Science per tick per level.
  - Logistics Stations: +50 Money per tick per level.

### 2. User Interface (UI)
- [x] **View Switcher:** Three-layer navigation (Orbit, Surface, Research).
- [x] **Orbit View Component:**
  - Visual representation with orbiting stations.
  - Build panel for station construction.
- [x] **Navigation:** Right-side layer buttons with scroll-snap behavior.

### 3. Integration
- [x] Stations integrate with the existing `tick` loop.
- [x] UI consistent with the "Scientific and Industrial" tone.

### 4. Contracts System
- [x] **Companies:** 10 persistent industrial entities.
  - Titan Mining, Nova Research, Zenith Logistics, Orion Heavy Industries,
  - Galactic Energy, Atlas Construction, Pulsar Electronics, Stellar Bio-Tech,
  - Aegis Security, Deep Space Exploration.
  - Each has a level and experience points.
- [x] **Contracts:**
  - **Types:** Logistics, Research, Commercial, Balanced.
  - **Conditions:** 
    - Time Limit: Contract fails if not completed within X seconds.
    - Fragility: Contract fails if more than Y rockets explode while active.
  - **Rewards:** Money, Science, and Company XP.
- [x] **UI:** Contracts dashboard with available offers and active mission status.

## Acceptance Criteria
- [x] Player can switch between Surface, Orbit, and Contracts views.
- [x] Player can build a Space Station in Orbit view if they have enough resources.
- [x] Contracts are generated based on company levels.
- [x] Active contracts track failures (explosions) and time correctly.
- [x] Completing contracts grants rewards and levels up companies.

## Implementation Notes

### Navigation System
- Vertical scroll-snap between Orbit, Surface, Research layers
- Horizontal scroll-snap on Surface between Spaceports and Contracts
- Visual indicators and keyboard-accessible navigation

### Contract Types
Each type has different resource multipliers:
- **Logistics:** 2x cargo, 0.2x science, 0.5x money requirement
- **Research:** 0.2x cargo, 3x science, 0.3x money requirement  
- **Commercial:** 0.3x cargo, 0.2x science, 2x money requirement
- **Balanced:** 1x all resources

### State Persistence
- Auto-save every 30 seconds
- Save on page unload
- localStorage-based persistence
