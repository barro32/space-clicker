# AI Game

This is an idle game built with React, TypeScript, and Vite. The game is about managing resources, building rockets and spaceports, and generating money and science.

## How to Play

The goal of the game is to accumulate as much money and science as possible.

- **Build Rockets:** Rockets are your primary producers. You can build them for a cost.
- **Build Spaceports:** Spaceports house your rockets. Each spaceport has a limited capacity.
- **Manage Spaceports:** You can toggle spaceports between "cargo" mode (to generate money) and "science" mode (to generate science points).
- **Explosions:** Be careful! Rockets have a chance to explode, and in rare cases, they can cause a chain reaction and destroy an entire spaceport. You can clear the debris from explosions to recover some money.
